# Alerting and Detection Strategy (ADS) — Rule 100014

## Goal

Detect data being archived with PowerShell `Compress-Archive` (T1560 Archive Collected Data). An adversary bundles collected files into an archive to stage them before exfiltration.

## Categorization

- **ATT&CK technique(s):** `T1560` — Archive Collected Data
- **Tactic(s) (v20):** Collection
- **Lab rule_id:** `100014`
- **Source Sigma rule:** `rules/sigma/T1560_powershell_compress_archive.yml` (original, written for this lab)

## Strategy Abstract

Keys on Sysmon Event 1 where OriginalFileName is PowerShell.EXE and the command line contains Compress-Archive. It only sees Compress-Archive when the cmdlet appears on a new process's command line.

## Technical Context

Hand written because sigma_to_wazuh skips multi-selection conditions. Chains on 61603. Invoke-AtomicTest runs the atomic in a child powershell.exe, so the cmdlet appears in that child's command line. Defender blocked the compression in every run (it flagged a file in the user profile), so no archive was written and no Event 11 was logged. The Event 1 command line was still captured, so the detection holds.

```xml
<!-- Rule 100014 - PowerShell Compress-Archive data archiving -->
<!-- MITRE ATT&CK: T1560 - Archive Collected Data -->
<!-- Sysmon Event ID 1 - Process Creation -->
<!-- Hand written from rules/sigma/T1560_powershell_compress_archive.yml (sigma_to_wazuh skips multi-selection conditions). -->
<rule id="100014" level="8">
  <if_sid>61603</if_sid>
  <field name="win.eventdata.originalFileName" type="pcre2">(?i)^PowerShell\.EXE$</field>
  <field name="win.eventdata.commandLine" type="pcre2">(?i)Compress-Archive</field>
  <description>T1560: PowerShell data archiving - $(win.eventdata.commandLine)</description>
  <mitre>
    <id>T1560</id>
  </mitre>
</rule>
```

## Blind Spots and Assumptions

Compress-Archive run inside an existing PowerShell session creates no new process and no Event 1, so it evades. That gap is why the baseline was changed to spawn a child PowerShell (commit c059eda). Other archivers evade: tar.exe, 7-Zip, WinRAR, makecab, and .NET ZipFile calls. PowerShell 7 (pwsh.exe) evades because its OriginalFileName is pwsh.dll. PowerShell script block logging (Event 4104) would close the in-process gap, but it is outside this Sysmon-only lab.

## False Positives

Admins and scripts archive logs and folders with Compress-Archive. The baseline archives an owned folder in a spawned PowerShell (manifest action `archive-logs`), so the rule fired once per run: FP cost 5 across 5 runs in both passes, precision 0.375. Before commit c059eda the baseline ran Compress-Archive in-process, which produced no Event 1 and would have measured an FP cost of 0 by construction.

## Tuning Decision

Tuning was not applied. The atomic (`dir $env:USERPROFILE -Recurse | Compress-Archive -DestinationPath $env:USERPROFILE\T1560-data-ps.zip`) and the baseline (`Compress-Archive -Path <folder> -DestinationPath <zip> -Force`) both run Compress-Archive in a child powershell.exe started by PowerShell, so even the parent process matches. The remaining differences are the source and destination paths and the recursive listing, and filtering on those would game the baseline, since an adversary can archive any folder. Archiving with Compress-Archive is not separable from benign administration at the single-event level, so the rule stays at coverage 2 and the FP cost is reported as the finding.

## Validation

- **Positive test:** Atomic T1560 #1 "Compress Data for Exfiltration With PowerShell" (GUID 41410c60-614d-4b9d-b66e-b0192dd9c597), PowerShell executor.\
&emsp;*Result:* **Detected**, 3 lab runs.\
&emsp;*Latency (Sysmon event `systemTime` minus run start):* **0.539 s / 0.603 s / 1.025 s.** Defender blocked the compression itself, so the detection is of the attempt.

- **Converter fidelity:** Not converted (multi-selection condition). Written by hand and confirmed live with the atomic.
- **Built-in comparison:** the stock run fired only 92027 (level 4, PowerShell spawned PowerShell, mapped to T1059.001), a generic hit. In the lab runs 100014 outranked 92027 at level 8.
- **Negative test:** FP cost 5 across 5 baseline runs (1 per run), the same in both passes.

## Priority

Suggested alert level: ***8***

## Response

*Analyst Action:* Read `-Path` and `-DestinationPath` from the command line. Archiving a user profile, documents, or credential stores, or writing the archive to a temp or staging folder, is escalated, followed by a check for outbound transfer of the archive.
